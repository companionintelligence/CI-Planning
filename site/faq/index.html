Companion Planning / FAQ

Frequently asked questions

Short answers about your data, your phone, optional AI and Google Calendar, sign-in and backups.

What is Companion Planning?

A private planner for tasks, time blocks, habits, routines and objectives. It runs on a server you control, and you open it in a browser. The native iPhone and Android apps are in preparation.

Who runs the server?

You do, or someone you trust. Run the public Docker image on a computer you control, or install Companion Planning from the Companion Hub store on a Companion Hub appliance.

Where is my data stored?

Tasks, time blocks and tags live in one SQLite file on the server. In the Docker image, the file is /data/companion.db, on the data volume you mount at /data.

Does my data leave my network?

The apps send your data only to the server address you enter. Some features use the internet: Google Calendar sync when you connect it, Web Push notifications, and error reports from released images, which you can turn off with CI_TELEMETRY=off.

Can I use it on my phone?

Yes. Open your server's address in the phone's browser and add it to your home screen. The native iPhone and Android apps are in preparation. They connect to your server with the same address and sign in with a username and password.

Does it need AI?

No. The AI features are optional. They use an Ollama model or an OpenAI-compatible endpoint that you configure. Without one, the AI features stay hidden.

How do people sign in?

With a username and password. The operator creates accounts under Settings → Accounts, and each new account gets a link to set its password.

Can I connect Google Calendar?

Yes. Add a Google OAuth client under Settings → Connections, then each person connects their own Google account. Reading events into the planner is the default. Writing changes back to Google is a separate switch that is off by default.

Can I back it up?

Yes. The project README describes three options: scheduled snapshots built into the server, Litestream for streaming replication, and export and import for a single account.

How do I get help?

Email support@ci.computer. The support page lists what to include.
