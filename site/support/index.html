Companion Planning / Support

Get help with Companion Planning

Email support@ci.computer with the details below. The setup guide and the FAQ answer most questions first.

What to include

  • How you run it: the Docker image, the Companion Hub store, or a source checkout.
  • The image tag or version, if you know it.
  • The device and browser you use. Once the apps are available, include the app version too.
  • The steps that led to the problem, and any error message you see.

Remove passwords, the SESSION_SECRET value, Google client secrets and other credentials before you send anything.

Check that the server answers

Open the server's address followed by /api/health, for example http://192.168.1.20:3848/api/health, in a browser on the same network. If that address does not answer, the server is stopped or your device cannot reach it.
