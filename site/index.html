Everything a day needs, in one planner

Today, the calendar, the backlog and your goals share one app. You plan in one place, and the data stays on the server you run.

Today

The day at a glance: overdue, due today, scheduled and open counts, a focus card, and a planner grid for placing time blocks.

Calendar

Day, week and month views, with Export, Review and Schedule Day controls.

Tasks and objectives

Priorities, tags, habits, routines and time blocks. Goals, projects and objectives form one tree, with an audit history.

Reminders

In-app reminders, plus Web Push notifications from your server once you allow them in the browser.

Your server, your data

Everything is stored in one SQLite file on the server you run. Use a desktop, a mini PC, a home server or a Docker host.

Optional local AI

Connect an Ollama model or an OpenAI-compatible endpoint for briefings, task extraction and grooming. Without a model, the AI features stay hidden.

Up and running in three steps

You set up the server once. Your phone and laptop only need its address.

  1. 1

    Run the server

    Start the public Docker image on a computer you control, or install Companion Planning from the Companion Hub store. Set your time zone so that "today" is right.

  2. 2

    Open it in a browser

    Go to the server's address, for example http://192.168.1.20:3848. On a phone, add the planner to your home screen.

  3. 3

    Sign in

    Sign in with the username and password you set. The operator adds more people under Settings → Accounts.

Your data stays on your server

Your plans stay in one file on a server you run. Here is everything that can leave it.

  • Tasks, time blocks and tags live in one SQLite file on the server you run.
  • The apps send your data only to the server address you enter.
  • Google Calendar sync stays off until you connect it. Writing changes back to Google is a separate switch, and it is off by default.
  • The AI features use a model you configure, such as Ollama. Without one, they stay hidden.
  • Web Push notifications go through the browser's push service, once you allow them.
  • Released server images send error reports. They contain errors only, are scrubbed, and never include your data. Set CI_TELEMETRY=off to turn them off.

Questions

What is Companion Planning?

A private planner for tasks, time blocks, habits, routines and objectives. It runs on a server you control, and you open it in a browser.

Do I need a server?

Yes. Companion Planning is a window onto your own server. You can run the public Docker image on a computer you control, or install it from the Companion Hub store on a Companion Hub appliance.

Can I use it on my phone?

Yes. Open your server's address in the phone's browser and add it to your home screen. The native iPhone and Android apps are in preparation.

Does it need AI?

No. The AI features are optional. Connect a model, such as an Ollama model, and they appear. Without one, they stay hidden.
