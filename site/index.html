Companion Planning

Your planner, on a server you run

Companion Planning is a private, local-first planner for tasks, time blocks and your day. Your plans are stored on the server you set up, and you open the planner in a browser.

How it works Ask a question

What's inside

  • Today. The day at a glance: overdue, due today, scheduled and open counts, a focus card, and a grid for placing time blocks.
  • Calendar. Day, week and month views, with export and a schedule-day control.
  • Tasks. A backlog with priorities and tags, plus habits, routines, time blocks and objectives. Goals, projects and objectives form one tree.
  • Optional AI. With a local Ollama model, the planner adds briefings, task extraction and auto-scheduling. These stay hidden until Ollama is reachable.
  • Optional Google Calendar. Once you connect it, your events are read into the planner. Writing changes back to Google is a separate setting, and it is off by default.

How it works

  1. Run the server. Start Companion Planning on a computer you control, such as a desktop, a mini PC or a home server. Run it from source with Node.js 22 or newer, or with Docker.
  2. Open the planner. Go to the server's address in a browser. On a phone, you can add the planner to your home screen.
  3. Sign in. Sign in with an account on that server.

Your data

  • Tasks, time blocks and tags live in one SQLite file on the server you run.
  • The optional AI features run on a local Ollama model.
  • Google Calendar sync stays off until you set it up.

What you need

  • A computer or home server that runs Node.js 22 or newer, or Docker.
  • A current browser for the planner.
  • The iPhone and Android apps are being prepared. Until they are available, open the planner in your phone's browser.
