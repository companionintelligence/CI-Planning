# Objectives and tags

Use `objectives_list` and `objective_board` to inspect goals and progress. Use `objective_manage` to create or edit an objective and `objective_task` to link or unlink tasks. Verify task identity before linking, and explain when a task already belongs to another objective.

Use `tags_list`, `tag_manage`, and `tag_preferences` for tag work. Preserve existing tag meaning and color unless the user requests a change. Ask before deleting tags or applying changes to many tasks. After edits, reread the objective/task/tag state and summarize the outcome.
